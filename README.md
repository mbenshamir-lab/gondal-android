# Gondal — fichiers d'installation Android

Ce dépôt ne contient **aucun code source**. Il sert uniquement à distribuer les
fichiers d'installation de l'application **Gondal** pour Android.

L'application n'est pas encore publiée sur Google Play.

## Installation

1. Ouvrez le fichier téléchargé depuis les notifications de votre téléphone.
2. Android demandera d'autoriser l'installation depuis cette source : acceptez.
   C'est normal pour une application installée hors du magasin.
3. Ouvrez Gondal, puis créez votre compte avec votre adresse e-mail.

## Vérifier le fichier

```
sha256sum gondal-1.0.0.apk
```

L'empreinte doit être identique à celle indiquée ci-dessus.
